# Animation starting patterns

Read [animation](animation-workflow.md) for timing/data ownership. For one operation use the
[technique index](technique-index.md); for a combination:

| Intended result | Recipe |
| --- | --- |
| Limited character gesture, facial event and secondary response | [Upper-body gesture](recipes/character-gesture.md) |
| Constant-speed parts, thread following or exploded mounting | [Moving assembly](recipes/mechanical-motion.md) |

Recipes explain interactions without requiring reproduction of their original asset.
The [whole-asset index](implementation-examples.md#motion-and-simulation) includes scenes,
previews and checks to repeat. Reopen after Action/slot changes: construction-session previews can retain
stale evaluation. Native controls alone do not certify [target exports](export-workflow.md).
